# Kubri POS Customer Onboarding Checklist

Use this checklist for every new pilot customer. Complete one copy per customer.

## Customer Record

- Customer/business name:
- Owner name:
- Owner email:
- Owner phone:
- City/country:
- Business type:
- Billing plan:
- Paid branch count:
- Branch limit:
- Onboarding date:
- Support channel confirmed:

## 1. Collect Business Details

- [ ] Legal business name.
- [ ] Arabic business name if applicable.
- [ ] VAT number if registered.
- [ ] CR/license number if available.
- [ ] National Address details.
- [ ] Business city.
- [ ] Contact name.
- [ ] Contact email.
- [ ] Contact phone.
- [ ] Number of branches.
- [ ] Product/service type.

## 2. Collect VAT/ZATCA Readiness Info

- [ ] Confirm whether VAT registered.
- [ ] Confirm invoice type needs.
- [ ] Confirm ZATCA Phase 2 readiness.
- [ ] Confirm Fatoorah OTP process owner.
- [ ] Confirm branch legal details.
- [ ] Confirm invoice language preference.
- [ ] Explain Kubri supports ZATCA Phase 2 invoicing workflows and QR invoices.
- [ ] Avoid certification, approval, partner-status, guarantee, or absolute-compliance claims.

## 3. Create Tenant/Client As Super Admin

- [ ] Log in as active super admin.
- [ ] Create client/tenant.
- [ ] Confirm tenant details.
- [ ] Set branch limit.
- [ ] Confirm onboarding status.
- [ ] Confirm tenant is active.

## 4. Create Owner Account

- [ ] Create owner account with verified owner email.
- [ ] Generate setup link.
- [ ] Copy setup link.
- [ ] Send setup link privately by WhatsApp or email.
- [ ] Record setup link sent time.

## 5. Confirm Owner Password Setup

- [ ] Owner opens setup link.
- [ ] Owner sets password.
- [ ] Owner logs in.
- [ ] Owner setup completion is tracked.
- [ ] Resend setup link if expired.

## 6. Create Branch

- [ ] Create first branch.
- [ ] Confirm branch belongs to correct tenant.
- [ ] Confirm branch is active.
- [ ] Confirm branch does not exceed paid branch limit.
- [ ] Add additional branches only if approved/paid.

## 7. Create Branch Username/Password

- [ ] Create branch user for correct branch.
- [ ] Set username.
- [ ] Set temporary password or reset flow.
- [ ] Share credentials privately.
- [ ] Confirm branch user login.
- [ ] Confirm branch user sees branch operational pages.
- [ ] Confirm branch user cannot access Super Admin or other branch data.

## 8. Configure Invoice Settings

- [ ] Business name.
- [ ] VAT number.
- [ ] Address fields.
- [ ] Invoice prefix.
- [ ] Receipt footer.
- [ ] Logo setting.
- [ ] Invoice language.
- [ ] VAT mode.
- [ ] QR invoice behavior.

## 9. Configure Printer

- [ ] Test browser print.
- [ ] Configure device printer if needed.
- [ ] Configure Electron/direct printer if using desktop app.
- [ ] Print test receipt.
- [ ] Record printer model and connection type.

## 10. Configure Products And Opening Stock

- [ ] Create product categories.
- [ ] Create products/services.
- [ ] Set prices.
- [ ] Set VAT treatment.
- [ ] Set stock tracking where applicable.
- [ ] Enter opening stock where applicable.
- [ ] Confirm POS product list.

## 11. Configure Suppliers And Customers If Needed

- [ ] Create suppliers for purchasing.
- [ ] Create customer records if B2B invoicing is needed.
- [ ] Confirm customer VAT number for standard invoice cases.
- [ ] Confirm branch scoping for created records.

## 12. Configure ZATCA Onboarding

- [ ] Confirm branch legal details.
- [ ] Confirm OTP owner is ready.
- [ ] Run sandbox/compliance flow if applicable.
- [ ] Run production onboarding flow if applicable.
- [ ] Confirm status.
- [ ] Submit test invoice where appropriate.
- [ ] Record any ZATCA error and support action.

## 13. Run Test Invoice

- [ ] Open POS.
- [ ] Add product.
- [ ] Complete cash checkout.
- [ ] Complete card checkout if relevant.
- [ ] Complete split payment if enabled.
- [ ] Confirm invoice detail.
- [ ] Confirm invoice appears in reports.

## 14. Run Receipt Print

- [ ] Open test invoice receipt.
- [ ] Print receipt.
- [ ] Confirm business details and QR.
- [ ] Confirm printer formatting is acceptable.

## 15. Explain Day Closing

- [ ] Explain opening register/session.
- [ ] Explain cash/card totals.
- [ ] Explain closing cash.
- [ ] Explain variance.
- [ ] Explain day/session report.

## 16. Explain Support Channel

- [ ] Share `support@kubri.shop`.
- [ ] Share `https://wa.me/971561373210`.
- [ ] Ask customer to include branch, invoice number, screenshot, and time.
- [ ] Explain pilot support expectations.

## 17. Record Payment And Coverage

- [ ] Confirm monthly or yearly plan.
- [ ] Record payment received.
- [ ] Confirm paid branch count.
- [ ] Confirm next due date.
- [ ] Explain 7-day money-back guarantee.
- [ ] Confirm no free trial.

## 18. Final Handover

- [ ] Owner login confirmed.
- [ ] Branch login confirmed.
- [ ] POS tested.
- [ ] Receipt tested.
- [ ] Reports tested.
- [ ] Branch limit set.
- [ ] Support channel confirmed.
- [ ] Known limitations explained.
- [ ] Customer approved go-live.
